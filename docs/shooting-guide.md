# 촬영 가이드

목표: 같은 색 샘플을 조명만 바꿔서 찍는다. 조명 말고 나머지 조건은 전부 같게 유지한다.

## 1. 준비물
- 색 샘플 약 30개: 색종이·페인트 칩·단색 옷·단색 물건. 무늬·광택이 강한 것은 피한다.
- 배경지: **흰색 또는 밝은 회색 무광 종이** (A3 이상). 모든 사진에서 같은 배경지를 쓴다.
- 조명: 전구색 LED 스탠드, 주광색 LED 스탠드 (나머지는 창가·교실 형광등·휴대폰 플래시)
- 촬영 기기 1대로 통일. 기종과 카메라 설정을 기록한다.

## 2. 샘플 목록 만들기 (촬영 전)
- 샘플마다 번호(01~30)와 정답 색을 팀원 전원이 합의해서 `data/samples.csv`에 적는다.
- 의견이 갈리는 샘플은 빼지 말고 "경계 샘플"로 표시한다 (신뢰도 기능 평가에 쓴다).
- 11색이 고르게 들어가게 한다. 색마다 2~3개, 헷갈리는 조합(갈색/주황, 빨강/갈색, 파랑/보라)은 더 넣는다.

## 3. 파일명 규칙
`물체번호_정답색_조명_번호.jpg` → 예: `03_red_warm_2.jpg`

코드를 영어로 쓰는 이유: `cv2.imread`가 Windows에서 한글 경로를 못 읽는다.

| 정답색 코드 | 뜻 | | 조명 코드 | 뜻 |
|---|---|---|---|---|
| black | 검정 | | sun | 창가 햇빛 |
| white | 흰색 | | shade | 그늘 |
| gray | 회색 | | fluor | 형광등 |
| red | 빨강 | | warm | 전구색 LED |
| orange | 주황 | | cool | 주광색 LED |
| yellow | 노랑 | | flash | 휴대폰 플래시 |
| green | 초록 | | | |
| blue | 파랑 | | | |
| purple | 보라 | | | |
| pink | 분홍 | | | |
| brown | 갈색 | | | |

## 4. 찍는 방법
- 배경지 위에 샘플을 놓고, **샘플이 화면 가운데에서 가로·세로 절반 정도**를 차지하게 찍는다.
  (코드가 가운데 50% 영역에서 대표 색을 뽑고, 배경지는 조명 추정에 쓰인다.)
- 조명당 5장: 정면 1장 + 각도·거리를 조금씩 바꿔 4장.
- 한 조명에서 찍을 때는 다른 조명을 끈다. 섞이면 그 조명 조건이 아니게 된다.
- 촬영자 그림자가 샘플에 걸리지 않게 한다.
- 플래시는 다른 조명을 최대한 줄이고 30~50cm 거리에서 찍는다.

## 5. 카메라 설정 (초반에 정해야 함)
휴대폰 자동 화이트밸런스는 조명 차이를 미리 줄여버린다. 둘 중 하나로 정한다.
- A. 프로 모드에서 화이트밸런스를 고정 (예: 5000K)하고 찍는다 → 조명 차이가 그대로 남아 보정 효과가 잘 보인다.
- B. 자동 화이트밸런스로 찍는다 → 실제 사용 환경에 가깝지만 방법 간 차이가 작게 나올 수 있다.

시간이 되면 일부 샘플만 A·B 둘 다 찍어서 비교 항목으로 쓴다.

## 6. 기존 앱 비교용 기록
같은 자리·같은 조명에서 기존 앱(Color Blind Pal 등)으로도 샘플 가운데를 찍고, 앱이 말한 색 이름을 `data/app_results.csv`에 적는다.
열: `물체번호, 조명, 앱이름, 앱이 말한 색`

## 7. 찍은 뒤
- 사진을 `data/raw/`에 넣고 `python src/evaluate.py data/raw` 를 실행한다.
- `[건너뜀]` 메시지가 나온 파일은 파일명을 고친다.
