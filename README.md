# 조명에 강한 색약 보조 색 인식 카메라

> 🚧 **진행 중** · 컴퓨터비전 개인 프로젝트 (2026)
> 현재 단계: 규칙 기반 파이프라인과 합성 데이터 평가까지 완료 → 실제 촬영 데이터 수집 중 → CNN·전이학습 비교 예정

주변에 조명 단서가 있으면 **자동으로 조명을 보정**하고, 단서가 없거나 색이 경계에 가까우면 **"불확실"이라고 솔직하게 알려주는** 색 인식 프로그램입니다.

## 왜 만들었나

- 카메라가 찍는 색은 대략 **물체 반사율 × 조명 색**입니다. 그래서 조명이 바뀌면 같은 물체도 다른 색 이름이 나옵니다.
- 일반 사용자는 앱이 틀리면 알아채지만, **색약 사용자는 결과를 스스로 확인할 방법이 없습니다.** (한국 성인 남성 색각이상 유병률 약 5.6%)
- 기존 색 인식 앱(Color Blind Pal, Color Grab 등)은 플래시를 켜거나 사용자가 흰색 기준을 직접 찍는 **수동 보정** 방식이고, 조명별 정확도를 공개하지 않습니다.

그래서 이 프로젝트는 "맞히는 것"뿐 아니라 다음 두 가지를 숫자로 검증하는 것을 목표로 합니다.
1. **조명 간 일관성**: 조명이 바뀌어도 같은 물체에 같은 색 이름을 말하는가
2. **불확실 표시의 정직성**: "확신"이라고 말한 결과는 실제로 더 정확한가

## 접근 방법

```
입력 이미지
  → 조명 단서 판단 (화면의 색 다양성)
      ├─ 단서 있음 → 조명 보정 (White Patch)
      └─ 단서 없음 → 보정하지 않고 "불확실" 표시
  → 가운데 물체 영역의 대표 색 추출 (블러로 안정화)
  → HSV 규칙으로 11색 이름 결정
  → H·S·V를 조금씩 흔들어 이름이 바뀌면 "불확실" + 두 번째 후보
       예) "갈색 또는 주황 (불확실)"
```

| 구성 요소 | 파일 | 내용 |
|---|---|---|
| 색 이름 | `src/color_naming.py` | 대표 색 추출, HSV 규칙 11색, 신뢰도 판단 |
| 조명 보정 | `src/illumination.py` | Gray World, White Patch, `auto`(단서가 있을 때만 보정) |
| 평가 | `src/evaluate.py` | 조명별 정확도, 조명 간 일관성, confusion matrix, 불확실 표시의 정직성 |
| 데이터 생성 | `tools/make_synthetic_hard.py` | 배경·조명·물체 크기를 바꾼 어려운 합성 이미지 990장 |

## 중간 결과 (합성 데이터 990장)

> ⚠️ 코드 검증용 합성 이미지 결과입니다. 실제 촬영 데이터 결과는 수집 후 추가합니다.

조명 6종(주광색 LED, 플래시, 형광등, 그늘, 햇빛, 전구색 LED)별 정확도:

| 방법 | cool | flash | fluor | shade | sun | warm | 전체 | 조명 간 일관성 |
|---|---|---|---|---|---|---|---|---|
| 보정 없음 | 0.87 | 0.88 | 0.84 | 0.65 | 0.92 | 0.51 | 0.78 | 0.33 |
| Gray World | 0.63 | 0.67 | 0.64 | 0.55 | 0.68 | 0.55 | 0.62 | 0.06 |
| White Patch | 0.75 | 0.77 | 0.78 | 0.70 | 0.79 | 0.72 | 0.75 | 0.06 |
| **auto (제안)** | 0.81 | 0.86 | 0.82 | 0.67 | 0.88 | 0.67 | **0.79** | 0.24 |

불확실 표시의 정직성:

| 방법 | 불확실 비율 | "확신" 결과 정확도 | "불확실" 결과 정확도 |
|---|---|---|---|
| 보정 없음 | 0.45 | 0.90 | 0.63 |
| **auto (제안)** | 0.56 | **0.91** | 0.69 |

**지금까지 알게 된 것**
- Gray World, White Patch를 무조건 적용하면 나무 책상 배경이나 물체가 화면을 가득 채운 사진에서 **보정 없음보다 나빠집니다.** 그래서 "단서가 있을 때만 보정"하는 `auto`를 만들었습니다.
- 물체가 화면을 가득 채운 사진에서 정확도가 0.39에서 0.75로 올랐고, 그중 94%에 "불확실" 표시가 붙었습니다.
- **남은 문제**
  - 조명 간 일관성이 아직 낮습니다(0.24).
  - 불확실 비율이 56%로 너무 높습니다.
  - 흰색↔회색, 주황↔갈색, 분홍↔빨강 혼동이 많습니다.
  - 이 문제들을 실제 데이터와 CNN으로 개선하는 것이 다음 목표입니다.

## 실행

필요한 것: Python 3, `opencv-python`, `numpy`, `matplotlib`

```bash
python tools/make_synthetic_hard.py        # 합성 이미지 990장 생성
python src/evaluate.py data/synthetic_hard # 평가 (결과는 results/에 저장)
python src/evaluate.py data/raw/natural    # 실제 촬영 데이터 평가
python src/name_photo.py 사진.jpg           # 사진 한 장의 색 이름 확인
```

실제 촬영 데이터 파일명은 `물체번호_정답색_조명_번호.jpg` 형식입니다(예: `03_red_warm_2.jpg`). 촬영 조건과 코드표는 [촬영 가이드](docs/shooting-guide.md)에 있습니다.

## 데이터 구성

| 폴더 | 조건 | 용도 |
|---|---|---|
| `data/raw/natural/` | 배경지 없이 실제 장소 | 주 결과 |
| `data/raw/paper/` | 흰색·회색 배경지 위 | 보정이 가장 잘 될 때의 상한선 |
| `data/raw/fill/` | 물체가 화면 가득 | 단서가 없을 때 "불확실"이라고 말하는지 확인 |
